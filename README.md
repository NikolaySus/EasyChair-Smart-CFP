# EasyChair Smart CFP

Jupyter notebook для подготовки данных ЛР-6: все таблицы Areas, очистка через
pandas, уникальные CFP и экспорт непосредственно в XLSX.

## Запуск

Из этого каталога в PowerShell:

```powershell
uv sync
uv run jupyter lab easychair_cfp.ipynb
```

Окружение создаётся в `.venv`, версии зависимостей фиксируются в `uv.lock`.
В VS Code открыть notebook и выбрать Python Environments →
`.venv\Scripts\python.exe`. Выполнять ячейки сверху вниз.

По умолчанию используется кэш `data/cache/`. После обрыва интернета повторить
ячейку сбора. Для нового снимка сайта установить `REFRESH=True` и повторить
весь сбор. Даты скачивания каждого Area сохраняются в выгрузке.

## Результат

`data/processed/easychair_cfp.xlsx` содержит:

- `conferences` — одна строка на уникальную ссылку CFP;
- `conference_areas` — принадлежности конференций разделам Areas;
- `conference_topics` — темы конференций;
- `area_summary` — контроль числа строк и охвата каждого раздела;
- `quality_issues` — нераспознанные значения и расхождения для ручной проверки;
- `raw_records` — исходные записи, включая повторения между Areas;
- `metadata` — источник, даты получения и показатели сбора.

Итоговый XLSX **не игнорируется Git**. Окружение, кэш и временные файлы игнорируются.
Notebook сохраняется с результатами выполнения для просмотра без повторных запросов.

## Использование в Superset

Начать с листа `conferences`: дата начала, дедлайн, `country_iso3` и общий счётчик
подходят для временных графиков и карты мира. Разрешить загрузку файлов в нужное
подключение PostgreSQL и выбрать соответствующий лист XLSX при импорте.

Для анализа по Areas загрузить лист `conference_areas` и объединить его с
`conferences` по `cfp_id` в SQL Lab или представлении базы данных.
Считать `COUNT(DISTINCT cfp_id)`, чтобы конференции из нескольких Areas не давали
дубли в общем счётчике. Колонки `areas` и `topics` в основном листе — текстовые
перечни; для отдельных категорий использовать таблицы связей.

Перед созданием карты проверить `quality_issues`: страна определяется по
последней части Location и справочнику ISO, неизвестные значения не угадываются.
Непустые неразобранные даты сохраняются в исходных колонках и отмечаются как проблемы.
При противоречии между Areas выбирается первое непустое значение, а все варианты
попадают в `quality_issues`. Пустые даты остаются пустыми.

Это снимок активных CFP из Areas, а не исторический архив. Проверка количества
строк обнаруживает неполный HTML или изменение пагинации и останавливает экспорт.
У маленьких таблиц без навигации сайт не показывает отдельный счётчик;
для них `reported_count` пуст, а `count_check` равен `navigation_disabled`.
